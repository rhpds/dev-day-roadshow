# Module 05 — AI-Driven App Modernization

### Status

**Not started.** Module scope defined by James Falkner (2026-10-08). Content authoring pending.

### Learning Objective

Analyze legacy workloads using the Migration Toolkit for Applications (MTA), accelerate code refactoring with Red Hat Developer Lightspeed, and deploy modern applications to Red Hat OpenShift.

### Lab Outline

Hands-on workshop guiding participants through analyzing, refactoring, and migrating a legacy JavaEE 7 insurance application to modern cloud-native standards on OpenShift:

1. **Phase 1: Code Analysis** (~10 min) — Run MTA assessment on the JavaEE 7 codebase, review migration reports and issue severity ratings
2. **Phase 2: AI-Guided Refactoring** (~10 min) — Fix legacy code using Developer Lightspeed to refactor to Quarkus/Jakarta EE
3. **Phase 3: Accelerate Modernization with Agents** (~10 min) — Refactor dependencies and impacted code using MTA's knowledge-based rules
4. **Phase 4: OpenShift Deployment** (~10 min) — Build, package, and verify the containerized application

### Technology Stack

- Red Hat OpenShift
- Red Hat Dev Spaces
- Red Hat Migration Toolkit for Applications (MTA)
- Red Hat Developer Lightspeed
- JBoss EAP 7, Red Hat Build of Quarkus

### Target Audience

Java developers, architects, and platform engineers refactoring legacy JavaEE monoliths.
