= OpenShift Dev Days Roadshow
include::partial$_attributes.adoc[]

Welcome to the OpenShift Dev Days Roadshow -- a collection of hands-on workshops where you experience modern application development and integration on Red Hat OpenShift.

== Available Modules

This roadshow consists of independent modules. Each module can be completed on its own, or you can work through multiple modules to gain a comprehensive understanding of OpenShift's capabilities.

[.tile]
****
xref:module-01/00-intro.adoc[Module 1: The Developer Experience]

Experience the full developer journey on OpenShift -- from self-service onboarding through Developer Hub, cloud-based development with Dev Spaces, AI-assisted coding, automated CI/CD pipelines, to GitOps-driven production deployments.

**Duration**: ~90 minutes
****

[.tile]
****
xref:module-02/00-intro.adoc[Module 2: Secured Software Supply Chain]

Build and deploy applications through a SLSA Level 3 compliant software supply chain -- vulnerability scanning with RHDA and ACS, keyless commit signing with Sigstore, pipeline attestations with Tekton Chains, policy validation with Conforma, signed release approvals, and deployment enforcement with Policy Controller.

**Duration**: ~90 minutes
****

[.tile]
****
xref:module-03/index.adoc[Module 3: Application Connectivity for AI]

Build AI data flows using Red Hat's integration technologies -- EDI ingest with Service Interconnect, event-driven messaging with Kafka and Matrix/Rocket.Chat, Agentic Apache Camel for AI customer support, and LLM governance with Connectivity Link.

**Duration**: Varies by lab
****

[.tile]
****
xref:04-module-04-ai-powered-troubleshooting.adoc[Module 4: AI-Powered Troubleshooting]

Learn how to troubleshoot applications on OpenShift using AI-powered tools -- investigate timeout issues, diagnose critical alerts, and build custom monitoring dashboards with OpenShift Lightspeed.

**Duration**: ~60 minutes
****

[.tile]
****
xref:module-05/module-05-01-goals.adoc[Module 5: AI-Powered Migration using MTA]

Modernize legacy Java EE applications to cloud-native Quarkus using the Migration Toolkit for Applications (MTA) and AI-assisted refactoring -- analyze code, apply custom rules, and deploy to OpenShift.

**Duration**: ~90 minutes
****

== Getting Started

Select a module above to begin. Each module includes its own introduction, environment details, and learning objectives.
