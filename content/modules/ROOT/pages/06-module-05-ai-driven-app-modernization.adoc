Welcome to the AI-Driven App Modernization module — a hands-on experience where you will analyze, refactor, and migrate a legacy application to modern cloud-native standards on Red Hat OpenShift, using automated analysis tools and AI-assisted code generation.

== Learning Objectives

* *Analyze Legacy Workloads:* Run automated code assessments using the Migration Toolkit for Applications (MTA) to identify API deprecations, framework incompatibilities, and containerization blockers
* *Accelerate Code Refactoring with AI:* Use Red Hat Developer Lightspeed directly within your IDE to receive AI-driven recommendations and automated code fixes for legacy JavaEE 7 dependencies
* *Deploy to OpenShift:* Package and run the modern application on Red Hat OpenShift using cloud-native runtimes

== Your Role and Mission

Your mission is to upgrade and refactor a legacy JavaEE 7 insurance application. You will identify technical debt using automated analysis, leverage developer-focused AI to fix outdated APIs and configuration files, and deploy the updated application to OpenShift.
